Jarvis Help

Microphone Permission On Surface

Modern Edge and Chrome only allow the microphone on a trusted secure page. If the mic permission toggle is missing or blocked, install Jarvis's local certificate first.

Download jarvis.local.crt

Install it into Trusted Root Certification Authorities, fully close Edge, then reopen https://10.0.0.242:8000.

Wake Word

After microphone permission is granted, Jarvis listens for its name automatically. The mic button is only for the browser's first permission prompt or recovery after permission is denied.

If this browser says it does not expose speech recognition, the browser itself is missing the required Web Speech API. Internet Explorer on Surface usually falls into this category. In Settings, set Microphone to Server and run wake word and speech-to-text on the Jarvis PC.

Server And Local Modes

Local mode uses this browser's microphone or camera and requires browser permission. Server mode uses hardware attached to the Jarvis PC and avoids browser permission problems on Internet Explorer.

Camera color matching works in Server mode from the Jarvis PC camera. Local camera mode only works in newer browsers that support camera access.

Music Sync

Music sync also uses the browser microphone. Say or type sync the lights to music. Any normal light color or effect command will stop music sync and take control again.
